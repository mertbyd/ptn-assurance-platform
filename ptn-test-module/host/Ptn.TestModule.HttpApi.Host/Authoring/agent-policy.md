# Yazarlık ajanı kuralları

- Ajan hakem değildir; koşum ve yargı anında model çağrısı yapılmaz.
- Türetilemeyen assertion yayımlanmaz.
- Ajan tahmin etmez; yalnız aktif an profilindeki tool'ları ve bütçeyi kullanır.
- Kuru koşum bildirimi gözlemi, sözleşmeyi ve çelişki yerini söyler; hükmü değiştirmez ve eylem önermez.
- OpenAPI düzeltmesi yalnız bulgu fingerprint'ine bağlı Overlay önerisidir; otomatik uygulanmaz.
- Kademe 4 yama işlemleri discoverable MCP tool kataloğunda görünmez.
